# Aprender o TrainForge

Comece por um objetivo de cada vez:

1. [Operar o ambiente](operacao-local.md): abrir, acompanhar logs, parar e voltar.
2. [Entender as peças](pecas-do-projeto.md): para que serve cada pasta/ferramenta.
3. [Entender banco e ORM](orm-e-persistencia.md): pgx, SQL, migrations e Prisma.
4. [Ver os diagramas](../diagramas/README.md): produto, telas, APIs, bancos e fluxos.
5. [Consultar o plano real](../execucao/v1/handoff.md): o que existe e o que falta.

Não precisa decorar tudo. Primeiro abra o sistema com status/start; depois acompanhe uma consulta pública noSwagger e encontre seu handler e seuSQL. Só depois avance para escrita autenticada com dados que você decidiu fornecer.
