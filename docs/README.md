A alimentação offline está em integração; o [handoff vigente](execucao/v1/handoff.md) registra os arquivos já baixados, recuperação do catálogo e próximos comandos.

Não é preciso ler todos os recibos ou inventários. Os guias acima são as entradas; detalhes técnicos gerados, provasJSON e acervosZIP ficam disponíveis para consulta. Cada documento diferencia proposta, implementação, teste técnico e aceite humano.

`arquivo/` e `referencias/` antigos saíram da navegação: repetiam snapshots e grafos de bases legadas. A informação histórica útil foi consolidada; os originais continuam no acervo com seus caminhos e hashes. Os antigos relatos por rodada não precisam permanecer como dezenas de instruções atuais.

OsSVGs de design são estudos históricos, não screenshots novos doAPK. SENAS foi mantido integralmente para a etapa final. Conteúdo privado, bancos, chaves, backups e corpos de pesquisa ficam fora doGit em`.local`.
