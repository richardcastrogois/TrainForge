## Recuperacao para o APK

`exerciseRecords[].sourceId/locator -> sources[].receipts -> inventario.sources[].sha256 -> recibo.bodyFile`. O complementoPR17 usa `existingFamilySupplement`. Cada recibo preserva URL inicial/final, data, estadoHTTP, bytes, hash e caminho original. Erros permanecem registrados como erros. FalhasTLS sem corpo nao ganham hash.

O contrato conserva `null` para campos ausentes e `importAllowed=false`. Antes de uma futura importacao, cada item precisara ligar publico/praticante/ambiente/finalidade, autor/qualificacao, versao/localizador, entrega, dose/unidade e direitos dos ativos efetivamente usados. Uma licenca de artigo nao cobre automaticamente CD, foto, video ou manual externo. Adaptacao editorial/clinica e implementacao sao fases posteriores, nao realizadas aqui.
