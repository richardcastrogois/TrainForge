# TrainForge

Aplicativo Flutter para Android e iOS, com conteúdo rastreável e dados reais. Primeiro ambiente de avaliação:Android local. Backend Go e PostgreSQL já implementados; catálogo separado em serviço/base próprios. Não há programa de treino liberado para prática.

## Estado

API 0.10.0/38 operações; catálogo 0.2.0; núcleo schema 13/30 tabelas e catálogo schema 2/4 tabelas. Execução ganhou persistência/API e uma tela na aba Atividade. Conteúdo próprio, adesão/agenda e aceite real de treino continuam pendentes; fotos, offline e demais jornadas mantêm seus critérios. [Entrega e limites](docs/execucao/v1/implementacao.md#atividade).

SomenteAndroid/iOS continuam como plataformasFlutter do produto. Dados, chaves e ferramentas locais ficam ignorados no Git. Push não é deploy. Sem contratação ou hospedagem autorizada nesta etapa.

As minhas anotações de pastas e ferramentas estão no [guia pessoal de aprendizado](docs/aprendizado/pecas-do-projeto.md).
